# haidennbann_search_system
Python・Flask・SQLite・HTML・CSSを用いた配電盤検索システム
#配電盤検索システム
## 概要
配電盤製品の型番や製品情報を検索するためのWebアプリケーションです。

## 使用技術

- Python
- Flask
- SQLite
- HTML
- CSS

## 主な機能

- ログイン機能
- 製品検索機能
- データベース連携
- 製品情報表示

## 開発背景

大学のプロジェクト活動の一環として開発しています。
企業から提供された課題に対し、配電盤製品を効率よく検索できるシステムの構築を目指しています。
